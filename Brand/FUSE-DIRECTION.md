## 参照から分かること

[Fuse のアイコン作例](https://wellmade.fyi/app/fuse/1235)を参照。
作品ページ本体が描画されなかったため、ページに明示された
[掲載画像](https://wellmade.fyi/api/media/1235-0_card.jpg)をブラウザで目視確認した。

- 白から薄いグレーの背景に、黒い形が大きく置かれている。
- 丸い塊の一部が細い接続部分で滑らかにつながり、一つの塊は離れている。
- 黒い面を保ち、輪郭にごく薄い光を乗せて奥行きを出している。
- 強い色、文字、細かい装飾に頼らず、輪郭と余白が印象を作っている。

素材の実体や制作方法は不明。ここでは「滑らかな黒い立体に見える」という視覚上の観察として扱う。
参照はアイコン一枚。以下の LP 方針は、この性質を Izzy に展開した提案。

## Izzy に取り入れること

方向を **白い余白、流れる輪郭、控えめな立体感** に置く。
「知っている英語を、話せる英語へ。」というブランドの核は維持し、見た目の説明を引用符に限定しない。

| 要素 | 検討する方向 |
| --- | --- |
| アイコン | 白い面に、丸い二つの腕が下でつながる黒い v。独自の輪郭を設計する |
| 色 | 白 `#FAFAFA`、黒 `#171717`、薄いグレー `#EFEFEF`。青はブランドの主役から外す |
| 質感 | 正面から見た浅い立体。広い黒い面と弱い縁の光。小サイズは単色でも成立させる |
| ロゴ | 既存の小文字 Archivo Italic を合わせて検討。図形は既存文字の切り出しにしない |
| LP | 白い余白に、一つの黒い造形と短い見出し。造形の近くに試せる一文を置く |
| 文字 | LP の見出しはサンセリフを試す。英語の発話例だけセリフ体にし、言葉との区別を作る |
| 動き | 操作に応じた短い変化に限定。常時浮遊・脈動する演出は加えない |

Fuse の丸い塊の配置や接続関係をそのまま移さず、Izzy では開いた v の輪郭を作る。
声や言葉が滑らかにつながる感覚は内部の設計意図とし、使う人に図形の意味を説明するコピーは足さない。
