## 第4ラウンド：izzy を一文字に畳む（2026-09-22、不採用）

ユーザーの「もっと izzy を一文字にまとめた感じのテイストに」を受けた検討。
採用中のふくらんだマークの質感はそのままに、4文字を**一つの塊**として読める形にした4案。
同じ日に、ユーザーから新しい絵が届いて上の決定になったため、4案は不採用。
アイコンは抽象のまま、文字はワードマークに任せる。

[比較ページ](monogram-icon.html) / [SVG マスター](studies/izzy-monogram/) /
書き出し：`node Brand/studies/izzy-monogram/make.mjs`

出発点は、いまのマークがすでに「zz」に近い折り返しを持ちながら、名前としては読めないこと。
4案とも i の点と y の尾を足し、重なった線が一つの面になるように組んでいる。

| 案 | 組み方 | 強み | 懸念 |
| --- | --- | --- | --- |
| A ひと筆 | i の軸から y の尾まで、一本の帯を三度折り返す | 一つながりの塊で輪郭が最も強い。現行の性格に近い | 小さいと izzy ではなく記号として読まれる |
| B 傾き | A を13°傾ける | 現行マークの斜めの流れを残す。移行の距離が最も小さい | 傾けるほど文字として読みにくい |
| C ならび | i と y を柱にし、間に zz を押し込んで正方形に収める | 名前として最も素直に読める | zz が詰まって細い。29pt で zz が一本に見えやすい |
| D 2段 | iz と zy を2段に積み、太らせた文字どうしを接する | 文字が太いまま正方形を埋められる | 中央で2段が接する密度。y の尾と下段の z の重なり |

作り方：フォントは使わず、丸い断面の帯（線の太さと丸い端点）として描いた骨格。
ふくらみは明暗の層による近似で、採用時は現行アイコンと同じ質感で作り直す。
比較ページは 1024px のマスターを 160 / 60 / 29 px と単色で並べ、小サイズの読みと輪郭を確認できる。

外した案：現行マークの二つの腕をそのまま残し、点と尾だけを足す「継ぎ」。
横棒と丸い端点が残るため、izzy ではなく `s` に読めた。

未確認：実機のホーム画面、iOS のダーク・色付きアイコン、ワードマーク（Figtree Medium）との並び、利用者の反応。

## 第3ラウンド：名前を Izzy に（2026-09-19）

ユーザー判断で、名前を vow から **Izzy** に変える方針。アイコンは小文字の izzy を横1行に並べ、文字を少しずらす。

vow から変える理由：App Store で「vow」を検索すると、日本で「スマホ依存対策 - Vow」、米国で Vow のスクリーンタイム管理・アファメーションなど、
同じ習慣づくりのジャンルのアプリが並ぶ。「vow」単独のストア名は取得済みで使えなかった。日本の学習者には読み方（ヴァウ／ボウ）が揺れやすく、「誓い」は重い。
Izzy は「イジー」と読みが一つで「easy」に近い。App Store の「izzy」検索は IZZY（キックボードのシェアサービス）、IZZY TV、STRONG BY IZZY（フィットネス）、izzi（通信会社）で、
英語学習・習慣づくりのジャンルには見当たらない。i の点と y の尾が上下に伸びるため、横1行でも正方形を埋められる。
懸念は、人の名前なので会話相手のキャラクターや AI を期待されうること、名前から中身が分からないこと（ストア名の副題で補う）。

[SVG マスター（通常・ダーク・色付き）](studies/izzy-icon/)

**選んだ案：大きく弾む・中央寄せ（2026-09-19）** — [izzy-bounce-centered.svg](studies/izzy-icon/izzy-bounce-centered.svg)
（ダーク・色付きは同じ名前に `-dark` / `-tinted`）。
元の配置は外枠の中央に置いていたため、文字の重心が中央より左下（x 505, y 525 / 1024）にあった。
重心を (512, 506) に置き直し、大きさを 92% にして角丸から余白を取った。
傾きが大きいと2つの z の角が接したため、字間を 34 → 64（フォント単位）に広げた。
配色は比較ページの既定のラベンダー `#A999FF` で書き出しているが、配色はまだ確定していない。

**書体：Outfit Black（2026-09-19）**。同じ組み方で OFL の太いサンセリフ12書体を比較した（[測定値](studies/izzy-icon/font-comparison.json)）。
z の斜めの線と横線の太さの比は Outfit が 0.99 で最も均一（Gabarito・Poppins・Lexend・Onest は 0.81〜0.85 で斜めが細い）。
i の点と縦線の幅の比も 1.02 で、点だけが目立たない。y の尾がまっすぐで角ばった z とそろう
（Figtree・Plus Jakarta Sans・Onest は y の尾だけが曲がる）。次点は Gabarito。
数値は1字を縦800pxで描画して測った目安。`studies/izzy-icon/` の SVG はすべて Outfit Black（丸い文字の案だけ Fredoka Bold）で書き出し直した。

| 案 | ずらし方 |
| --- | --- |
| **大きく弾む（選んだ案）** | ずれ・傾きとも大きめ（±6〜8°）。Pieter Pot に近い。中央寄せ・92% で清書へ |
| 少し傾ける | 上下のずれに ±3〜4° の傾き |
| 上下だけ | 傾けず上下にだけずらす。いちばん落ち着いている |
| 右上がり | 左から右へ少しずつ上がる |
| 点が跳ねる | 「少し傾ける」の i の点だけ右上へ浮かせる。点を動きの主役にできる |
| 丸い文字 | 「少し傾ける」を Fredoka Bold で。やわらかい |

a〜e は Figtree Black、f は Fredoka Bold の輪郭をそのまま1字ずつ回転・移動した形（自動で膨らませた形ではない）。
字間は文字の輪郭の幅で揃え、2つの z が重ならないようにした。比較ページの推奨配色はラベンダー `#A999FF`、
ほかにクリーム・バター・ミント・コーラル・スカイ・墨を切り替えて確認できる。

未確認：J-PlatPat での商標（区分 9・41）、App Store Connect でのストア名「Izzy」の空き、実機のホーム画面と iOS 上のダーク・色付きアイコン。
リポジトリ・ストア・LP の名前は、この時点ではまだ vow のまま。

## 第2ラウンド（2026-09-18）

第1ラウンドの3案はユーザー判断で「単純すぎる」として不採用。
参考として [Pieter Pot](https://wellmade.fyi/app/pieter-pot-supermarkt/1357) と
[Hily](https://wellmade.fyi/app/hily-dating-app/1481) が挙げられた。

2つに共通すること：黒一色の平面と明るい地色一色、形が正方形の7〜8割を占める、
意味の記号ではなく傾き・弾み・膨らみといった形の動きで人格を出す、文字がもとだが書体を置いただけに見えない。
第1ラウンドは細い Regular の文字をまっすぐ置き、帯や円の意味で個性を出そうとしていた点がずれていた。

## 第1ラウンド（2026-09-17、不採用）

[SVG マスター](studies/icon-candidates/) / [出典データ](icon-candidates-sources.json)

### 結論（当時）

**推奨は「マーカー」。** 白地に、黄色のマーカーを引いた小文字の vow。
覚えたい表現に線を引く動作をアイコンにし、アプリ内の例文ハイライトと同じ見た目にそろえる。

対抗は「しるし」（黄色の面に、vow を刻んだ墨色の印章）。
変更を最小にするなら「なまえ」（ラズベリーの面に、クリーム色の vow）。

判断の問い：

1. ホーム画面で、他の英語アプリの中から一目で見つけられるか。
2. 設定や通知の 29pt でも、vow だと分かるか。
3. アイコンの形が、アプリで毎日することにつながっているか。

3つすべてに答えられるのはマーカー案。これはデザイン上の判断で、利用者テストによる順位ではない。

### 調査で分かったこと

| 観察 | vow への判断 |
| --- | --- |
| 英単語アプリ Vocabulary（米国ストア評価 217,338 件）のアイコンは、ベージュにセリフ体の V。現行 vow（グラファイトに v）や前回の紙と文字組の案は、一文字を中央に置く構造が同じ | 頭文字だけのアイコンをやめる |
| 日本でよく使われる英語アプリは、mikan（オレンジ）、abceed（白地に赤い輪）、スタディサプリ ENGLISH（紺）、Santa・Speak（青）、Duolingo・TOEIC 公式（緑）に集中 | 黄色かラズベリーを主色にする |
| Wellmade で目立つアイコンは一色の面に形ひとつ（Posh、Klarna、Tise、Granola、Headway、Sticky Notes） | 1024px でしか見えない細部を持たせない |
| Capwords は練習完了で日付入りの円形スタンプ、Duolingo は炎と曜日のチェック、mikan はストア説明で学習データの蓄積と「1,000日連続」を紹介。炎は Duolingo・Spark・BurnBar・Opal・Vocabulary に共通 | 完了画面のチェックと Today の炎を、ブランドの形に置き換えられる |
| Vocabulary は「I commit to 3 days」（3日の先に7日）、Opal は長押しで満ちきると確定する「Hold to Commit」 | 既存の「1日の新しい表現の数」に、最初の3日の目安を添える |
| Elevate は正しい綴りに変わった単語に色面、Perplexity は読み上げに合わせて語句が色付く | 既存の例文ハイライトをアイコンと同じマーカーの見た目にする |

### 3案

| | マーカー（推奨） | しるし | なまえ |
| --- | --- | --- | --- |
| 形 | 白地、墨の vow、下半分に黄色の帯 | 黄色の面、墨の円に vow と内側の輪 | ラズベリーの面、クリームの vow |
| 色 | `#FFFFFF` `#1E1D1B` `#F8D548` | `#F3C443` `#1E1D1B` | `#D23F69` `#FFF4EA` |
| 29pt | vow と読める | 黄色に黒い丸として認識、文字は読めない | vow と読める |
| アプリへの展開 | 例文ハイライトを墨の文字＋マーカーの面に。完了画面で今日の数にマーカー。アクセント色に合わせた別アイコン | 完了画面に日付入りの印、統計のカレンダーと Today の炎を印に | 既定アクセントをピンクに |
| 既定アクセント（新規のみ） | Blue → Yellow | Blue → Yellow | Blue → Pink |
| 懸念 | 白地は色の面より目立ちにくい。学校の勉強を連想する人もいる | コインや認証バッジにも見える。実装が最も大きい | 形に意味がなく、色に頼る |

3案とも、承認済みの Archivo Regular Italic（幅85%）ワードマークの輪郭から作成。
小さいサイズで線が細くならないよう、アイコンでだけ輪郭に線幅（パス単位で 7〜8）を足している。
これはアイコン用の光学調整で、ワードマーク本体の字形は変えていない。

途中で外した試作：

- 波形のふちの印章は、王冠やボトルキャップに見えた。
- 黒い楕円に白目の顔は、日本ではまっくろくろすけを連想させた。
- 顔の要素を小さくした案は、40pt 以下で目と口が消えた。

### 続けたくなる仕掛け（どの案でも使える）

優先度順。いずれも未実装。

1. **完了の瞬間にブランドのしるし（小）**：`CompletionMark` のチェックを、選んだ案の形に。一度だけの動き、視差効果を減らす設定では表示のみ。
2. **最初の3日を区切って見せる（小〜中）**：目標設定の直後から Today の進捗に3日の区切り、次は7日。途切れても最高記録と練習日は残す。
3. **読み上げに合わせてマーカーを引く（中）**：例文の再生中、対象の表現に左から線を引く。
4. **アイコンの色を選べる（小）**：マーカー案の場合、アクセントカラーと同じ色の別アイコン。
5. **「今日のひとこと」ウィジェット（中〜大）**：今日の表現と意味を表示し、タップで Today を開く。

### 決めたあと

1. `scripts/build_brand.mjs` を選んだ案に更新し、AppIcon（通常・ダーク・色付き）、favicon、タッチアイコン、共有画像を書き出す。
2. 新規インストール時の既定アクセントを案の色に合わせる。既存の選択は保持。
3. TestFlight の次のビルドで、実機のホーム画面と通知の見え方を確認する。
4. 2案で迷う場合は、両方を別アイコンに入れたビルドで比べる。
