# Wellmade 追加調査 — Izzy の形、金属、LP

調査日：2026-09-13。これは追加調査と制作への提案で、採用済みデザインの宣言ではない。

## 結論

**小文字の Izzy 全体を使う方向は続けてよい。次に詰めるのは、字形を保ったまま、金属の反射をどこまで整理するか。**

特に参考になるのは、金属の面づくりでは Retro、文字全体のまとまりでは Posh、
ブランド素材と実際の UI の関係では Offmenu の Super、製品の見せ方では Norma。
それぞれから取り入れる部分を分けて考える。

最初の調査では、少数の作品から引用符や青へ結論を急いだ。
今回の比較では、言語学習だから発話の記号を作る必要はなく、名前の3文字自体を識別の中心にできると判断した。

## 調査の範囲

[Wellmade の公開一覧](https://wellmade.fyi/api/entries)には取得時点で1,208件。
タグ別にアイコン192件、ロゴ62件、ブランディング86件、Websites 26件を候補抽出に使った。
タグは重複する。全件の画像を見たという意味ではない。

そこから **21作品、静止画像25点と動画内の確認可能な2場面**を目視比較した。
Norma はリンク先の[現行サイト](https://nor.ma/)も確認した。
掲載作品が現在の正式ブランドと同じであるとは限らず、売上・認知度・成約率の効果は調査していない。

動画は一部のシーク先で映像が表示されなかった。Super は約3.2秒、Norma は約9.25秒の場面を根拠とし、
未表示の後半や動きの全体を確認済みとは扱わない。@hours の Norma 動画は読み込みが完了せず、21作品に含めていない。
個別ページで本文が空になる場合は、公開一覧に紐づいた掲載メディアをサイト上で直接開いて確認した。

一覧の説明文は選別だけに使用。例えば Retro の自動説明は文字の読み方が画像と一致しないため、分析に採用していない。
画像は外部サイトへの埋め込みが制限されていたため、比較用の参照画像をローカルへ転載せず、作品リンクを記録した。

## 優先して見たい7作品

### 1. Retro — 暗い面を残すクローム

[作品](https://wellmade.fyi/app/retro/1370) / [掲載画像](https://wellmade.fyi/api/media/1370-0_w720.webp)

白地に、厚みのある金属の形。面のかなりの部分が暗く、窓のような大きい白い反射が入る。
明暗の細かな線を全域へ足すのでなく、大きな面ごとに光がまとまっている。

Izzy への判断：最も近い金属表現の参照。v・o・w それぞれに同じ方向の光を与え、3文字を一つの物として見せたい。
ただし、この作品の分割された図形や、深く膨らんだ厚みは転用しない。

### 2. Posh — 文字全体をアイコンにする

[作品](https://wellmade.fyi/app/posh/1020) / [掲載画像](https://wellmade.fyi/api/media/1020-0_w720.webp)

黒い正方形に、太く傾いた小文字の posh が横いっぱいに入る。字間が詰まり、4文字が一つの輪郭として見える。

Izzy への判断：Izzy 全体をアイコンに入れる考え方の参照になる。
現在の字形を大幅に太くする提案ではなく、3文字全体の占有率と余白を検討するための事例。
大きいロゴ画像を余白ごと縮めるだけでは、この密度にならない。

### 3. Super / Offmenu — 立体と平面の関係

[作品](https://wellmade.fyi/@weareoffmenu/1048)

約3.2秒の場面では、立体のプラス記号、パレット、平面の Super ロゴ、輪郭線の UI アイコンが一緒に並ぶ。
大きなブランドオブジェクトの質感を、すべての文字や操作へ広げてはいない。

Izzy への判断：大きなクロームの Izzy と、通常表示の平面 Izzy を同じブランドとして併用できる。
LP の主役や告知では金属、ナビゲーションや小さな表示では平面、という役割分担を検討する。
淡い黄緑・水色の配色は今回の Izzy の方向へ持ち込まない。

### 4. Norma — 造形から実際の行動へ

[Wellmade の作品](https://wellmade.fyi/@driceroland/1171) / [現行サイト](https://nor.ma/)

掲載動画の確認場面では、金属の円盤が机上の中心にある。
現行サイトでは、その円盤へスマートフォンを近づける場面と、スキャンする行動を伝える見出しが冒頭に置かれている。
装飾物を鑑賞させるだけでなく、使い方へ視線をつないでいる。

Izzy への判断：クロームの名前を見せた後、すぐに一文を思い出して声に出す体験へつなぐ。
金属は Izzy の機能そのものではないので、架空のハードウェアのように延々と回転させない。
Norma の実写の机、商用数値、推薦ロゴ、割引ポップアップは参照対象にしない。

### 5. Opal — 反射を抑えて形を残す銀色

[作品](https://wellmade.fyi/app/opal/440) / [掲載画像](https://wellmade.fyi/api/media/440-0_w720.webp)

黒い背景に、輪郭の丸い銀色のリング。面には大きく緩やかな明暗があり、細かな映り込みが少ない。

Izzy への判断：ユーザーの指定は鏡面クロームなので、この質感へ変更する決定ではない。
小さいサイズで反射を整理するときの比較対象として有用。光沢を減らした案と鏡面案を、同じ字形で比較したい。

### 6. Obsidian / Bakers — 豊かな素材と静かな情報

[作品](https://wellmade.fyi/@studiobakers/769)

1枚目は大きな岩の質感と白いロゴ。4枚目は、その質感を使った面と、文字中心の白い名刺を組み合わせている。

Izzy への判断：強い素材を使う場所と、読む場所に差をつける。
LP 全体を金属にする必要はなく、一つの強い造形と、落ち着いた例文・説明の面でブランドを成立させる。
岩の表面や同作品のロゴは転用しない。

### 7. Syncspace / Studio Sphere — ブランドの形が説明を担う

[作品](https://wellmade.fyi/@0xsphere/791) / [掲載画像](https://wellmade.fyi/api/media/791-0_w1080.webp)

白い面の左に見出し、右に短い説明。下の太い経路と矢印が、複数の流れが合流する様子を示している。

Izzy への判断：見出しの下のビジュアルは、アプリで何が起こるかに結びつける。
Izzy では経路や矢印を借りるのでなく、一つの場面と、自分で答えを試してから開く例文で伝える。

## 今の Izzy 案で直したいところ

### 反射が文字の線を分断して見える

現行の生成案は、v・o・w の各ストロークに白いハイライトと細い黒い縁が多く入る。
40 / 60 / 80 / 128 / 256 CSS px の同じ画像幅で平面版と比較すると、小さい表示ではクロームが線画のように見えた。
これは目視によるデザイン判断で、利用者による判読テストではない。画像内の余白を含む比較であり、実際のホーム画面も未確認。

[サイズ比較](../.build/Brand/wellmade-research/size-study.html)

次の試作では、文字の中心にまとまった明るい面か暗い面を残す。
反射は数本の大きな流れにし、各文字で照明の向きを揃える。細い輪郭線を重ねて金属感を作らない。

### 一枚のレンダリングで全サイズを兼ねない

| 用途 | 次の制作方針 |
| --- | --- |
| LP の主役・大きい告知 | 小文字 Izzy 全体。ユーザーが指定した鏡面の反射を見せる |
| アプリアイコン | 同じ Izzy 全体から始める。正方形内の占有率を調整し、映り込みを簡略化して比較する |
| ナビゲーション・小さな署名 | 既存の平面ワードマークを基本にする。金属の3文字を極小まで縮めない |

この使い分けは調査からの提案。アイコンを V 一文字へ戻す決定はしていない。
既存の Archivo Regular Italic・幅85%のベクターを基準にし、生成画像の微妙な字形の差を新しい正式字形にしない。

### LP がクロームの展示だけで終わらないようにする

最初の画面で、金属の Izzy と「どんな英語をどう練習するか」が一緒に伝わる構成にする。
造形が主役の領域と、読みやすい平面の領域を作り、次の順で見せたい。

1. クロームの Izzy、短い見出し、実際の一場面。「ひとこと試す」で例文を自分で開く。
2. 対応する実アプリの練習画面。思い出す、声に出す、確かめる、という行動を見せる。
3. 表現との出会い、復習、利用条件。収録数や設定の詳細はここで伝える。

ヘッダーの文字や CTA まで金属にする必要はない。余白、文字の大きさ、白黒の比率で揃える。
「高級」「未来的」などの言葉を足すより、反射と組版の仕上がりで印象を作る。
